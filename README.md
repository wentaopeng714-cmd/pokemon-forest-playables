# Pokémon Forest Playables

Two standalone browser game prototypes, packaged separately for import.

- **Don't Wake Snorlax** — drag berries, manage noise, and stop in time to rescue the round.
- **Treehouse Trouble** — place Pokémon on a tilting deck and reposition them to keep it balanced.

Download one game ZIP from Releases and use its root `index.html` as the entry. Each ZIP embeds its runtime, forest scene, models, and textures. No build step is needed.

These compatibility candidates were tested locally with WebGL 1 and restrictive texture-loading policies. Actual Loopit import remains to be verified.
