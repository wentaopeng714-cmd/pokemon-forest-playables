# Scene test assets

Source: https://github.com/06wj/pokemon

- `gengar-animated.glb`: Gengar, embedded textures, skeletal clips `attack`, `happy`, `idle`, `run`, `sleep`, `walk` (case-sensitive).
- `forest-grove.glb`: Grove environment, embedded resources, no animation clips.

Models are provided unchanged from the source. Pokémon assets remain subject to their respective rights holders; upstream code licensing does not grant Pokémon asset rights.
